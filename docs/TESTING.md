# Как проверить систему

Есть три уровня проверки. Начните с первого: он не требует ни домена, ни Telegram.

---

## 1. На ноутбуке в браузере (10 минут)

Нужно: установленный **Docker Desktop** (запущенный) и **Git**.

```bash
git clone https://github.com/almosistore-droid/Umar-beekeeping.git
cd Umar-beekeeping
docker compose -f docker-compose.dev.yml up --build
```

Первый запуск занимает 3–5 минут: скачиваются образы и пакеты. Готово, когда в логах появилось
`Local: http://localhost:5173/`. Это окно не закрывайте.

**Во втором окне терминала** (в той же папке):

```bash
# демо-данные: 2 пасеки, 10 ульев, 10 маток
docker compose -f docker-compose.dev.yml exec backend python -m app.utils.seed --telegram-id 111111

# строка для входа (действует 7 дней)
docker compose -f docker-compose.dev.yml exec backend python -m app.utils.dev_init_data 111111 --first-name Умар
```

Откройте **http://localhost:5173**. Появится экран «Откройте в Telegram», а под ним — блок
«🧪 Вход для проверки на компьютере». Вставьте туда строку из второй команды и нажмите «Войти».
Вы войдёте как администратор.

> Совет: в Chrome нажмите F12 → значок телефона (Ctrl+Shift+M) и выберите iPhone — так вы увидите
> приложение в размере телефона.

Этот блок входа есть **только** в режиме проверки. На боевом сервере его нет. Строка
подписывается токеном бота и проверяется сервером так же, как настоящий вход из Telegram.

**Документация API (Swagger):** http://localhost:8000/api/docs

**Остановить:** `Ctrl+C` в первом окне. Данные сохраняются до следующего запуска.
Начать с чистой базы: `docker compose -f docker-compose.dev.yml down -v`

## 2. Что проверить (чек-лист этапов 1–2)

### Вход и роли
- [ ] Вход работает, на главной ваше имя и роль «Администратор».
- [ ] «Ещё» → «Пользователи»: войдите во второй вкладке браузера (режим инкогнито) с другим ID:
      `... dev_init_data 222222 --first-name Помощник`. Новый пользователь появится в списке
      как «Наблюдатель». Он видит ульи, но не видит кнопок «＋ Улей», «Заменить матку» и т. д.
- [ ] Поменяйте ему роль на «Помощник» → он может менять силу семьи, но не создавать ульи.

### Пасеки и ульи
- [ ] «Ещё» → «Пасеки» → «＋ Пасека»: создайте пасеку, кнопкой 📍 подставьте координаты.
- [ ] «Ульи» → «＋ Улей»: создайте улей с семьёй.
- [ ] Попробуйте создать второй улей с тем же номером на той же пасеке → понятная ошибка.
- [ ] Дата установки в будущем → ошибка «не может быть в будущем».
- [ ] Фильтры «Сильные», «Слабые», «Без матки», поиск по номеру и по коду матки.

### Матки
- [ ] «Матки» → «＋ Матка»: дата рождения 15.06.2024 → возраст считается сам («2 года 3 месяца»),
      цвет метки подставляется автоматически.
- [ ] Год рождения в будущем, неверная оценка → ошибки на русском.
- [ ] В карточке улья «Подсадить матку» → матка появилась, в «Истории» запись.
- [ ] «Заменить матку» на другую → у старой статус «Заменена», в истории «M-105 → M-205».
- [ ] Перенос матки в другой улей → прежний улей становится «Без матки».
- [ ] «Убрать» матку со статусом «Погибла» → её нельзя подсадить снова.

### История не теряется
- [ ] Измените номер улья (✏️) → адрес страницы (UUID) тот же, в истории «Изменён номер».
- [ ] «Сменить семью» → во вкладке «Семьи» видны обе: старая закрыта, новая активна.
- [ ] Статус улья «Продан» → улей ушёл в «Архив», его семья и матка отмечены проданными,
      вся история осталась.

### Одновременное редактирование
- [ ] Откройте редактирование одного улья в двух вкладках, сохраните в первой, затем во второй →
      «Улей уже изменил другой пользователь».

## 3. Внутри Telegram на телефоне (с ноутбука)

Telegram открывает Mini App только по **HTTPS-адресу из интернета**. Для проверки без сервера
подойдёт бесплатный временный туннель Cloudflare.

1. Впишите в файл `.env` (в корне проекта; создайте из `.env.example`) **настоящий** токен бота и
   свой Telegram ID:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ADMIN_TELEGRAM_IDS=ваш_id
   ```
   и перезапустите: `docker compose -f docker-compose.dev.yml up --build`
2. Установите [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
   и запустите:
   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```
   Он покажет адрес вида `https://xxxx-xxxx.trycloudflare.com`.
3. В Telegram → **@BotFather** → `/mybots` → ваш бот → **Bot Settings → Menu Button** →
   вставьте этот адрес. (Или `/newapp`, если ещё не создавали Mini App.)
4. Откройте бота на телефоне и нажмите кнопку меню → приложение откроется внутри Telegram,
   вход произойдёт автоматически.

Адрес туннеля меняется при каждом запуске `cloudflared`. Для постоянной работы нужен сервер с
доменом (см. README → «Установка на сервер»).

## 4. Автоматические тесты

Запускаются сами на GitHub при каждом изменении: вкладка **Actions** в репозитории, зелёная
галочка ✅ означает, что все тесты прошли.

Смотреть результат удобнее всего там же, на GitHub.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| `Cannot connect to the Docker daemon` | Запустите Docker Desktop и подождите, пока он загрузится |
| Порт 5173, 8000 или 5432 занят | Закройте другую программу или перезагрузите компьютер |
| «Не удалось войти: signature is invalid» | Строку входа нужно сгенерировать заново после смены токена в `.env` |
| «initData has expired» | Сгенерируйте новую строку (действует 7 дней) |
| Белый экран | `docker compose -f docker-compose.dev.yml logs frontend --tail=50` |
| Ошибки сервера | `docker compose -f docker-compose.dev.yml logs backend --tail=50` |

Пришлите вывод логов или скриншот — разберёмся.
